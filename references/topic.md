# 主题、今日低粉高表现、选题

`plan search --query <主题> --hot` 的今日范围为配置 IANA 时区午夜到任务启动时，报告 UTC 边界。只把发布时间落在边界内的作品放进今日表。热榜进入时间与作品发布时间不同；旧作品另放 `hot_reference`。抖音视频热榜是 TikHub 的榜单数据，不等同“官方抖音热榜”；小红书热榜缺失时写缺失。关键词扩展必须列依据与原词。报告本次搜索词、页数、去重前后、截断原因，不声称平台“所有”作品。

`classification` 只有同时核实粉丝≤阈值、播放≥阈值才是“低粉高播放已验证样本”。粉丝未知是数据不足；播放未知但低粉且互动较高是互动候选。互动率需播放>0、点赞/评论/分享全部存在。相对账号基线只用目标发布前同账号最近作品，不含目标作品，少于十条为低置信。今日增长中的作品不可与曝光充足的旧作品宣称精确同比。机会排序是研究优先级，不是爆款概率。

已有表格默认标“待核源”；只有用户能说明它是可靠平台导出时，Agent 才可显式使用 `import --verified-import` 并在报告记录来源与覆盖。此标记仍不等于本次 TikHub 实测。

产出 `analysis/topics.md` 和 `analysis/topics.json`（格式见 [模板](../templates/topics.example.json)）：开头写 5–10 条建议，证据不足时更少；后写覆盖与限制。每条包括主题、原创角度、受众问题、为什么值得做、对应作品/评论链接、与现有内容差异、Bobo 切入点、制作可行性、置信度、优先级及原因。不能直接搬运原作者标题。没有合格作品时明确写“本次未找到符合条件且播放量可核验的样本”。
